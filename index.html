Adicionar dados do dia

Preencha os campos. Campos vazios não alteram dados existentes. Se escolher uma Hora, os campos (inclusive Logues/Tempo) são lançados só naquela hora, sem mexer no total do dia.

Importar arquivo Vonix

Suba o arquivo .csv ou .xlsx. O sistema reconhece as colunas automaticamente. Se o arquivo for um relatório de agentes filtrado por hora no Vonix, escolha a Hora abaixo pra lançar só naquela hora.

Importar outro arquivo

Suba qualquer arquivo .csv ou .xlsx. O sistema tenta reconhecer as colunas.
